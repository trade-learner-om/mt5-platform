# Docs and Changelog

1. Follow `docs/README.md` for context vs skills vs changelog.
2. Add `docs/changelog/YYYY-MM-DD-short-slug.md` for significant behavior changes (match recent entries).
3. Keep `.cursor/skills/*/SKILL.md` thin; put detail in `docs/skills/`.
4. Update `docs/context/project-context.md` only for product-wide or architectural shifts.
