## 2026-06-21

### Changed

- Fixed the web maintenance-mode health gate in `apps/frontend-react/src/App.jsx` so maintenance/checking screens no longer return before later hooks run, resolving the production React hook-order crash (`Minified React error #310`) when backend availability changes.
- Fixed international crypto risk sizing so non-FX symbols like `BTCUSD` now use raw stop-loss price difference for quantity/risk calculations instead of forex pip math, and updated web/mobile distance copy to avoid labeling crypto moves as pips.
- Raised the price-alert Continuation Failure stop-loss cap for GOLD/XAU symbols from the generic 7-pip default to a dedicated 70-pip limit so valid gold setups are not rejected too early.
- Added `INDIAN_CRYPTO` as a third market selection in the current web UI and backend market model, with a dedicated in-app Delta Exchange India workspace shell kept separate from the existing International and Indian market flows.
- Softened live tick failure behavior during MongoDB outages by adding a short backoff in `market_data_stream.py`, so a down local Mongo instance no longer emits a full reconciliation traceback on every incoming tick.
