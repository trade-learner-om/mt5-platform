### Changed

- Adopted local Windows runtime for MT5 integration instead of Docker.
- Documented the `mt5-platform` local operations command.

- Moved backend secret generation into a helper script to avoid Windows batch parsing errors.
- Improved local restart cleanup by killing server process trees and replacing `timeout` with a non-interactive-safe wait.
- Removed backend reload mode from the local launcher so status and restart report a single backend server process.
- Changed MT5 validation to initialize with login, password, and server in one MetaTrader5 API call.
- Replaced MetaApi.cloud international account handling with encrypted local MT5 login/password/server credentials.
- Switched the frontend from the initial minimal dashboard to the reference SignalBridge UI workflow.
- Changed MT5 account creation to require a terminal path and verify that the connected terminal login/server match the account being added.
- Changed alert automation M1 pending-fill invalidation to 5 candles while keeping M5 at the existing 2-candle window.
- Changed alert-triggered Continuation Failure automation to require classified setup candles before entry, while keeping the alert-specific post-trigger high/low stop-loss rule.
- Changed alert automation stop-loss distance cap to allow 25 pips for JPY quote pairs while keeping the default cap at 7 pips.
- Changed alert automation pending orders to roll after a pre-fill SL breach candle closes, recreating the order with the latest post-alert high/low stop loss.
- Changed chart rendering to show active price alerts and refresh recent candles from MT5 while using bid-based live updates.
- Changed price alert UI/API to support editing active alerts and show live pips distance to alert price.
- Changed the price alert view so its header stays visible while scrolling and instrument alert groups can collapse.
- Changed price alert distance display to use normalized pip-based color coding and show distance chips in collapsed instrument headers.
- Changed the alert modal to reset inputs after close/save/cancel, autofocus the instrument field, submit on Enter, and cancel on Escape.
- Added a global `Ctrl+L` shortcut that opens the create alert modal over the current page.
- Added edit/cancel controls for running alert automation, including safe edits before pending/open orders and pending-order cancellation when stopping a run.
- Changed main Automation Continuation Failure to support per-instrument 1-minute or 5-minute candles and require a user SL mark with the existing SL buffer.
- Changed automation snapshots, lifecycle events, and setup/order rows to clearly mark forward-test mode as `dry_run` / Forward Test - No Broker Order.
- Changed Trade Planner creation to enable execution by default and cancel linked pending broker orders when execution is deactivated, plans are deactivated, or plans are deleted.
- Changed MT5 risk context so XAU/GOLD pip sizing uses a 0.01 gold pip instead of the default non-JPY FX pip size, while still using broker tick value and volume constraints.
- Changed GOLD skipped-setup handling so a skipped sell setup waits for the skipped candle high to break before considering another sell setup, with mirrored low-break behavior for buy setups.
- Changed GOLD strategy start flow to require manual high/low inputs when the current broker D1 candle has already wicked through PD high/low, arming those sides without body-close confirmation.
- Changed GOLD strategy SL distance cap from 40 to 50 XAU pips and prevented new trade initiation while any GOLD strategy position is open for the symbol.
- Fixed GOLD pre-cross start handling so entered high/low levels are post-start wick triggers, preventing immediate sell/buy arming before the manual level is crossed.
- Changed XAU/GOLD pip calculations so `0.10` is one pip and `0.01` remains the broker point/pippet for entry and stop buffers.
- Changed GOLD clean-SL re-entry handling so shorts wait for `max(PD/manual high, highest post-execution price)` and longs wait for `min(PD/manual low, lowest post-execution price)` before placing another trade.
- Added GOLD daily rollover so a no-position run stops and restarts on the next broker D1 candle using the latest closed D candle as PD; auto-stopped-for-day configs remain subscribed for the next daily start.
- Added GOLD trigger source selection: `Previous day` uses PDH/PDL, while `User selected` accepts one price and infers long below current price or short above current price.
- Added focused GOLD retry regression coverage for long and short pending-order cancellation followed by the next qualifying setup candle.
- Added Trading tab manual order options: retryable LIMIT order (one-time SL retry after clean stop) and automatic trade management (50% at 4R, remainder at target or runner).
- Added `manual_order_runtime.py`, `manual_context` on orders, `GET /orders/{order_id}/events`, Positions activity timeline, and unit tests for manual retry/trade management.
- Removed the legacy main Automation tab/runtime, `/automation/reversal-5m/*` routes, reversal service files, websocket `automation` payload, reversal stream hooks, obsolete reversal indexes, and Android Automation screen.
- Kept price-alert automation by moving shared candle pattern helpers into a neutral `candle_patterns.py` module.
- Changed Forex Strategy targets to be editable after position open with direction-aware 3R minimum, 1R target spacing, explicit exit quantities, optional first-target breakeven, and default 8R full exit when no targets are defined.
- Added Android Forex Strategy monitoring and target entry support.
