# Mobile Trend Pilot and Trap Reversal parity

## Summary

- Android and iOS strategy hub now matches web: **FSM Engines** (Trap Reversal), **Trend Pilot**, and **Trade Planner**.
- Trend Pilot mobile screens support live/backtest modes, multi-account start/stop, status pills, active runs, history detail, and backtest delete.
- Trap Reversal mobile screens support H1 level proof, start/stop (start hidden when symbol already running), and active engine list.
- Shared `StrategyStatusPill` / `StrategyStatusPill` composable uses adaptive success/warning/danger/accent soft backgrounds for light and dark themes.
